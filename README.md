# Travel Assistant

Travel Assistant is a full-stack trip-planning app. Create trips, organise activities, plan and track costs, and manage a packing checklist from one workspace.

The React frontend lives in `frontend/`; the ASP.NET Core API and PostgreSQL data layer live in `backend/`.

Start with the [app guide](documentation/app-guide.md) for local setup, architecture, features, and test commands. The [documentation index](documentation/README.md) links to deployment guidance, the product plan, and feature requirements.
